# Skill Usage

## Meta-Perception
- For any non-trivial task where a wrong initial framing is costly, read `meta-perception` before acting.
- If the skill mechanism does not trigger automatically, manually read the full SKILL.md from the shared skill directory: `~/.agents/skills/meta-perception/SKILL.md`.
- Always do this when the user explicitly mentions `meta-perception`, `/meta-perception`, debugging, root-cause analysis, architecture or design choices, research-heavy investigations, or underperforming ML experiments.
- For trivial tasks with an obvious and directly verifiable fix, state that the task is trivial and proceed without the full workflow.
