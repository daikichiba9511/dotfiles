## 更新内容の取り込み方

| 参照元の変更 | このスキルでの扱い |
|---|---|
| 翻訳調の比喩、擬人化、曖昧な話し言葉への対処を追加 | 主体、対象、観察できる処理や結果を具体的に書く指針として採用。単語だけによる禁止にはしない。 |
| 初出の概念が何の種類に属するかを先に示す | 種類、用途、必要な性質の順で紹介する。既知の用語は説明し直さない。 |
| 対比する定義の述部を揃える | 比較の軸と文の形を揃え、対応を読み取りやすくする。 |
| 図、表、コードの説明範囲と指示対象を明確にする | 別例の結果を持ち込まず、参照先を特定する指針として採用。 |
| 必要な反復と、新しい命題の追加を冗長と区別する | 同じ用語の再使用、条件、限定、比較のための反復を残す。 |
| 文字数や文数だけで冗長さを判断しない | 対象、条件、因果、適用範囲を失う圧縮を避ける。 |
| 整形セクションを削除 | ローカルの一文一行と段落間の空行は維持する。削除だけから、整形規則の禁止や否定を推測しない。 |

## 今回の会話から補う要素

| 不足していた観点 | 加える判断基準 |
|---|---|
| 自然な語の組み合わせ | 名詞に汎用動詞を添えた表現を見直し、分野で使われる動詞や訳語を選ぶ。 |
| 語句の意味関係 | 助詞を省略しすぎず、修飾する語を対象の近くに置く。 |
| 既知から未知への順序 | 読者が共有している対象から説明を進め、接続詞だけでつながりを作らない。 |
| 文の負担とリズム | 異なる説明の役割を分け、関連する短文は必要に応じてまとめる。 |
| 文脈に応じた省略 | 対象が一意なら省略し、対象が変わるところでは明示する。 |
| 語調と確かさ | 文書の用途に合う文体を選び、事実、推測、提案を区別する。 |

従来の「自然な文章より、論理の役割が明確な文章を優先する」は、意味と根拠の正確さを保ったうえで、論理の順序と言葉の自然さを両方整える方針に改める。

## 一律の規則として採用しないもの

参照元にある「イ形容詞＋です」の禁止、段落冒頭への接続表現の必須化、結論を最後に置く構成の固定は採用しない。
これらを日本語全般の正誤として扱わず、読者、用途、文脈に応じて判断する。
また、名詞、受動態、無生物主語、専門用語そのものを禁止する規則にはしない。
文末を散らすためだけの用語変更や、事実から推量への変更も避ける。

## 配置と確認方針

スキル本体には生成手順と判断基準を置き、判断が難しいときの具体例は `references/natural-japanese.md` に分ける。
参照元と適用範囲も補助資料に記載し、調査の経緯はこのノートに残す。
既存の編集用スキルやレビュー用スキルを自動で追加する手順は設けない。

フロントマター、参照ファイル、差分、適用範囲を確認し、chezmoi で対象スキルだけを配置する。
文体の改善効果については、構造チェックと文例の点検から言える範囲を超えて評価しない。
