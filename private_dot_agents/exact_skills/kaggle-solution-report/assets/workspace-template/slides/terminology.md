## ページごとの確認

各ページについて、タイトルと主張だけを読み、次の二点を答えられることを確認する。

1. 何についてのページか。
2. このページで何を理解すべきか。

`五つの判断`や`構造的な差`のように、本文を読まないと意味が決まらないラベルは使わない。数を使う場合は、その項目数自体に意味があり、項目を同じページで具体的に示せる場合に限る。
