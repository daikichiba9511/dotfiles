# Global Instructions

- Use `meta-perception` for non-trivial tasks where a wrong initial framing is costly.
- Use `japanese-tech-writing` when writing or revising substantial Japanese technical prose, not for short conversational responses.
- Use `reader-aware-japanese-writing` when generating or substantially rewriting Japanese prose. Fix the reader's assumed knowledge first, define every necessary technical term before use, and do not use jargon.
